## 0. 阅读须知：口径与证据分级

### 0.1 入榜口径（什么算"上海公司"）

本报告主榜单只纳入满足以下任一条件的主体：

1. **工商注册主体在上海**（公司全称含"上海"，注册地在沪）；或
2. **核心研发 / 运营总部在上海**，即便其集团母公司或注册主体在外地（此类会单独注明"双地 / 特例"）。

仅有上海子公司、分公司、销售办公室的企业**不进主榜**，统一放入第 9 章"外地对照附录"，例如：

- 翼菲科技（总部 2025 年中由济南迁至浙江台州玉环，上海仅子公司）；
- 钧舵机器人（苏州/哈工大系，张江设上海公司）；
- 爱仕达 / 钱江机器人（浙江温岭，2026 年在上海设"智能谷"）。

### 0.2 产业链口径（什么算"具身智能公司"）

本报告采用宽口径，覆盖围绕"让物理实体自主感知—决策—行动"的完整链条，并按赛道分层：

- **整机 / 本体**：人形、轮式人形、四足、工业 / 协作机械臂、康复与服务机器人；
- **具身"大脑" / 模型**：VLA、世界模型、世界动作模型、通用机器人大脑；
- **数据 / 训练场 / 动捕**：真机数据采集、动捕、语料库、虚实融合训练场；
- **灵巧手 / 触觉 / 末端执行器**；
- **核心零部件 / 关节 / 控制器 / 算力平台**；
- **平台 / 高校 / 大厂 / 政府生态**。

康复机器人、仓储 AMR、传统工业自动化企业与狭义"通用具身智能"公司分开归类，不混为一谈。

### 0.3 证据分级

- **A 级**：公司官网 / 官方新闻稿、政府门户、招股书 / 交易所文件、工商登记信息。
- **B 级**：权威媒体（新华社、人民网、科技日报、证券时报、第一财经、每经、36 氪 / 投资界 / 量子位等）报道，且与 A 级信息基本一致。

## 1. 执行摘要（5 条核心结论）

1. **上海已形成"张江双核 + 多点联动"的全国最完整具身智能产业链，但"整机强、大脑更热"是 2026 年的结构性变化。** 上海以浦东张江为核心承载区，构建"张江 AI 创新小镇（端侧芯片 / 具身模型 / 场景应用）+ 张江机器人谷（智能制造 / 系统集成 / 平台）"双核；官方口径张江聚集具身智能产业链企业 130 余家、人形机器人产业链企业近 80 家（科技日报，2026-06），另有"近 150 家"的更宽口径（财联社，2026-07）。2026 年上半年上海规上人工智能产业规模超 3300 亿元、同比 +22.6%（上海市政府 / GDPS，2026-10）。资本重心明显从本体转向"大脑"：2026H1 国内具身大脑公司吸金约 222.53 亿元（上海市企业出海平台引 IT 桔子，2026-08）。

2. **量产与"进厂"已经发生，但出货量口径必须分清"当期出货"与"累计下线 / 交付"。** 智元是规模化标杆：援引 IDC，2026 上半年人形机器人出货超 8600 台、约占全球（近 2.5 万台）35%、中国市场超 45%（B/C 级）；公司另有"第 20000 台产线机器人交付长隆"的累计口径（C 级）。全国层面，2026H1 中国人形机器人出货超 4 万台（《2026 年人形机器人产业发展报告》，新华网 2026-10 引用）。上汽金桥奥特能超级工厂的"能仔 1 号"成为中国汽车业首批真正投入量产产线的人形机器人之一（上海市政府，2026-10）。

3. **"大脑派"在上海密度全国最高，且分成三条互相竞争的技术路线。** ① VLA / 端到端派：它石智航（AWE）、蚂蚁灵波（LingBot，适配 17 品牌 20 构型）、灵初（Psi-R）；② 世界模型派：大晓（开悟 Kairos，商汤系）、穹彻（Noe-0）、模思（复旦 OpenMOSS 系）；③ 世界动作模型派：眸深（MotionGPT / STI-WM，把动作做成 token，非 VLA 主流）。加上数据派（觅蜂、库帕思、青瞳），上海在"模型 + 数据"层的厚度是其区别于深圳 / 北京的最大特征。

4. **触觉 / 灵巧手与核心零部件是上海被低估、但商业化最"硬"的一层。** 纬钛机器人（MIT GelSight 系，视触觉出货量称全球第一、覆盖全球 90% 灵巧手厂商、进小米手机产线，2026-11 完成数亿元 A 轮）；傲意科技（张江，仿生义肢 + ROHand，2026-03 完成 1.5 亿元 C1 轮）；傅利叶 FDH-6 灵巧手打到 ¥4,999；动界智控（上海机电 × 德昌）做关节。判断"真落地"的最硬证据正在从 Demo 转向"是否进量产 BOM、是否进真实产线节拍"。

5. **行业整体仍处早期，2026 是"部署元年"也是分化与出清的开始，需警惕三类泡沫。** 中国信通院《具身智能发展报告（2025 年）》明确"整体仍处发展早期"，存在数据—模型—本体—场景难闭环、路径 / 构型 / 数据方案三大"非共识"（新华网，2026-10）。数据有效率极低（上海交大李永露：约 12 万小时第一视角数据可用不足 5000 小时；11 万小时工厂视频乐观可用约 3%，量子位，2026-04）。风险案例达闼（北京）2025-10 被裁定破产清算，历史融资超 50 亿元、估值一度约 223 亿元。三类泡沫：**出货 / 下线口径混用、估值与营收脱节、"意向订单 / 框架协议"被当作收入。**

## 7. 风险、分歧与前景

### 7.1 行业阶段：仍是早期（权威定调）

- 中国信通院《具身智能发展报告（2025 年）》：整体仍处发展早期，"数据—模型—本体—场景"难闭环，商业模式、规模化量产、标准缺失；商用正从"科研试验"迈向"进厂入户"。三大非共识：**路径（数据 vs 模型孰重）、本体构型（通用唯一形态 vs 场景专用构型）、数据方案（真机 vs 仿真 / 合成如何混训）**（新华网，2026-10-19，A）。
- 全国已建成 70+ 训练场、在建 / 规划 40+，长三角 / 京津冀 / 珠三角三大集群；"具身智能数据集质量要求及评估方法"行标 2026-11-01 实施，数据从"规模导向"转"质量导向"（新华网，A）。
- 市场预测：赛迪预计未来 5 年复合增速 73%、2030 年全球具身智能市场约 2388 亿元（B）。

### 7.2 数据：最大的隐性泡沫是"小时数"

- 上海交大李永露（GM-100）：约 12 万小时第一视角人类行为数据，可用于 VLA 预训练的**不超过 5000 小时**；某 11 万小时工厂视频，乐观可用比例约 3%（量子位沙龙，2026-04，B）。
- 北京人形车正平提出 **VIP 仿真标准**（Visual / Interactive / Physical）：仿真成功率 90%+ 时，零样本迁移真机应至少 60–70%；仿真不能完全替代真机，但可大幅压缩真机依赖。
- 智源姚国才：一个人 10 年每天交互 10 小时才约 3 万小时，10 岁孩子已能完成海量任务——说明当前具身范式**数据利用率极低**，质量远比数量重要。
- 含义：觅蜂"千万 / 百亿小时产能"、各公司"10 万 / 50 万小时采集"应看**有效小时与跨本体复用率**，而非总时长。

### 7.3 三类需要读者自行打折的"数字"

1. **出货 / 下线 / 交付混用**：8600 台（2026H1 当期出货）≠ 15000 / 20000 台（累计下线或交付）；"全球占比 35%"依赖 IDC 口径与全球总量假设。
2. **估值与营收脱节**：多家公司成立 1–2 年估值数十亿到两百亿，但有真实营收的极少（眸深 2026 全年预计 5000 万元已属大脑派中的高营收）。"半年估值涨 10 倍"是一级市场情绪指标。
3. **意向 / 框架 / 合作 ≠ 收入**：开普勒数千台意向、眸深 × 颐家 10 万台康养、灵波中东 AFDE 框架、它石"数百台 / 千台"规划，均应与"首批已进厂 / 已签约金额 / 已回款"分开。

### 7.4 出清案例：达闼（警示，非上海在营健康公司）

- 达闼机器人（**北京**主体）2025-10-10 被法院裁定受理破产清算；截至 2026-10 累计被执行约 3530 万元。历史融资超 50 亿元、估值一度约 223 亿元，股东含软银愿景、阿里、富士康、华登等；2026-06 珠海格金六号基金要求支付回购款、罚息、违约金近 3 亿元（B/C）。上海曾有达闼主体，但其当前在沪营存状态需以工商为准，本报告**不将其列为在营上海公司**，仅作"高融资也会出清"的风险样本。

### 7.5 上海的优势与短板（观点，非事实）

- **优势**：产业链最完整（双核 + 8000/10000 家供应链平台 + 中试 + 标准 + 训练场）；大脑 / 模型 / 数据密度全国最高；高校（交大 / 复旦 / 同济 / 上理工）与国字号平台就近溢出；场景方（上汽、上海电气、百联、国大药房、国网 / 消防）愿意"放场景"；资本市场（临港基金、上海科创基金、徐汇 / 杨浦 / 静安国资 + 产业资本）活跃。
- **短板 / 变量**：① 最具消费级声量的本体（宇树在杭州、众擎 / 优必选在深圳 / 珠三角）不在上海，上海整机偏"工业 / 量产"而缺"现象级 ToC"；② 大脑派拥挤，可能出现同质化与估值透支；③ 国产算力 / 高端传感器（部分六维力、触觉原材料）对外依赖仍在；④ 真实付费、可持续的商业模式（卖铲、卖模型、卖工时、卖租赁）尚未收敛。

## 8. 结论与展望（2026 末 → 2027）

1. **2026 是"部署元年"，2027 将是"现金流元年"的筛选期。** 政策目标（2026 底百场景 / 万台、"十五五"10 万台进工厂）已把赛道推入规模验证；接下来市场会用"回款、复购、产线稼动率"而非"发布会演示"给公司定价。
2. **上海最可能跑出新巨头的位置是"大脑 + 数据 + 触觉 / 核心部件"，而非再赌一个现象级整机品牌。** 灵波、大晓、眸深代表三种大脑范式之争；纬钛 / 傲意代表已进 BOM 的硬科技；仙工智能证明"卖控制器 / 中台"可以上市并盈利。
3. **标准、训练场、CR 认证、数据质量行标的"规则制定权"会成为长期护城河。** 国地中心 + 上电科 + 库帕思 + 张江南平台，本质是把上海变成"具身智能的产业公共基础设施供应商"。
4. **并购整合与出清会同步发生。** 达闼式破产、上市公司产业资本（上海电气、上海机电、德昌、中车、小米、宁德时代）的入主 / 绑定，会让 2027 年的名单明显收敛；当前 40 家里相当部分 C 级线索公司可能被并购或转型。
5. **给读者的尽调建议**：看四件事——① 注册主体与融资是否有 A 级（官网 / 工商 / 招股 / 权威媒体）证据；② 出货 / 订单分清"意向、框架、签约、进厂、回款"；③ 数据看"有效小时"和跨本体复用，而非总时长；④ 触觉 / 部件看是否进客户量产 BOM、寿命 / 一致性 / 单价，而非实验室参数。
